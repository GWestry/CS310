HAND-DRAWN TRACE TEXT

Draw each problem on its own page. Copy the following exactly. On every page,
draw two boxes labeled STACK and HEAP/ADT. Under the boxes write:
BASE CASE:
UNWIND:
FINAL:
COMPLEXITY:

Use -> for next, <-> for next/prev, and -> HEAD for a circular link.

01
INPUT: 1->2->3->4
STACK: reverse(1) -> reverse(2) -> reverse(3) -> reverse(4)
HEAP: 1->2->3->4->NULL
BASE CASE: reverse(4) returns 4.
UNWIND: 4->3; 3->2; 2->1; 1->NULL.
FINAL: 4->3->2->1->NULL
COMPLEXITY: Time O(n), space O(n). Iterative space O(1).

02
INPUT: 1->2->3->4->5
STACK: middle(slow=1,fast=1) -> (2,3) -> (3,5) -> base
HEAP: 1->2->3->4->5
BASE CASE: fast is NULL or fast->next is NULL.
UNWIND: slow stops at node 3.
FINAL: middle = 3
COMPLEXITY: Time O(n), space O(n). Iterative space O(1).

03
INPUT: 1->2->3->2 (cycle)
STACK: cycle(slow=1,fast=2) -> (2,1) -> (3,3)
HEAP: 1->2->3->2
BASE CASE: fast is NULL means false; slow == fast means true.
UNWIND: slow and fast meet at node 3.
FINAL: cycle found = true
COMPLEXITY: Time O(n), space O(n). Floyd iteration space O(1).

04
INPUT: A=1->3->5, B=2->4->6
STACK: merge(1,2) -> merge(3,2) -> merge(3,4) -> merge(5,4)
HEAP: two sorted lists A and B
BASE CASE: one list is NULL; return the other list.
UNWIND: choose 1, then 2, then 3, then 4, then 5, then 6.
FINAL: 1->2->3->4->5->6
COMPLEXITY: Time O(n+m), space O(n+m). Iterative space O(1).

05
INPUT: 1->2->1->3->2
STACK: dedupe(1) -> remove(1) -> dedupe(2) -> remove(2)
HEAP: 1->2->1->3->2
BASE CASE: current node is NULL.
UNWIND: delete duplicate 1; delete duplicate 2.
FINAL: 1->2->3
COMPLEXITY: Time O(n^2), space O(n). Iterative space O(1).

06
INPUT: 3->5->1->4->2, x=3
STACK: partition(3) -> partition(5) -> partition(1) -> partition(4)
HEAP: original list; LOW=NULL; HIGH=NULL
BASE CASE: current node is NULL.
UNWIND: LOW gets 1, then 2; HIGH gets 3, then 5, then 4.
FINAL: LOW=2->1; HIGH=4->5->3.
COMPLEXITY: Time O(n), space O(n). Iterative space O(1).

07
INPUT: 1<->2<->3<->4
STACK: reverse(1) -> reverse(2) -> reverse(3) -> reverse(4)
HEAP: 1<->2<->3<->4
BASE CASE: current node is NULL.
UNWIND: swap next and prev at every node.
FINAL: 4<->3<->2<->1
COMPLEXITY: Time O(n), space O(n). Iterative space O(1).

08
INPUT: 1<->3<->5; insert 4
STACK: insert(1) -> insert(3) -> insert(5) -> base
HEAP: 1<->3<->5
BASE CASE: current is NULL or 4 belongs before current.
UNWIND: connect 3<->4<->5; repair both directions.
FINAL: 1<->3<->4<->5
COMPLEXITY: Time O(n), space O(n). Iterative space O(1).

09

STACK: erase(1) -> erase(2) -> found
HEAP: 1<->2<->3
BASE CASE: current is NULL or current value is 2.
UNWIND: connect node 1 directly to node 3.
FINAL: 1<->3
COMPLEXITY: Time O(n), space O(n). Iterative space O(1).

10

STACK: pair(1) -> scan(4,6,9) -> pair(4) -> scan(6)
HEAP: 1->4->6->9
BASE CASE: no outer node or no remaining scan nodes.
UNWIND: 4+6=10 returns true.
FINAL: pair found = true
COMPLEXITY: Time O(n^2), space O(n). Iterative space O(1).

11

HEAP: 1 child->3; 1 next->2
BASE CASE: current node is NULL.
UNWIND: visit child before next sibling.
FINAL: 1->3->2
COMPLEXITY: Time O(n), space O(n). Iterative stack space O(n).

12

HEAP: 1<->2<->3<->4

FINAL: 3<->4<->1<->2
COMPLEXITY: Time O(n), space O(n). Iterative space O(1).

13

15

16

COMPLEXITY: Time O(n), space O(1). Recursive traversal space O(n).

17
